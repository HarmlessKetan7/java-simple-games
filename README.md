# 🎮 Java Mini Games

A collection of fun and simple console-based games built using Java.

---

## 🗂️ Games Included

| Game | Description |
|------|-------------|
| 🧠 Quiz Game | Answer multiple choice questions and test your knowledge |
| ✂️ Rock Paper Scissors | Play the classic hand game against the computer |
| # Number Guess game | Guess numbres randomly |

---

## 🛠️ Requirements

- Java JDK 8 or above
- Any Java IDE (IntelliJ, Eclipse, VS Code) or terminal

---

## ▶️ How to Run

### Using Terminal
```bash
# Compile the file
javac Quizgame.java

# Run the file
java Quizgame
```

### Using an IDE
1. Clone this repository
2. Open the project in your IDE
3. Run the `main()` method in any game file
